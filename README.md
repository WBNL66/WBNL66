### 干活习惯 · How I work

- **能自托管就自托管** —— Docker Compose + Nginx + SQLite，少一个外部依赖就少一个故障点。
- **先读日志再改代码** —— 大部分「玄学问题」都在日志里写着，告警降噪比加新功能更值钱。
- **改动必留回滚点** —— 备份、md5 校验、一键还原，是深夜里最好的保险。
